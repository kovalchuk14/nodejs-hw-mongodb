# 📇 Contacts API

A **Node.js + Express** backend application for managing user accounts and contact information.
It provides secure authentication, email verification, password recovery, and full CRUD operations for user contacts.
Includes interactive **Swagger documentation** for easier testing and collaboration.

---

## 🚀 Features

- 🔐 **User Authentication** — Registration, Login, Logout using JWT tokens
- 📧 **Email Verification** — Users receive an email to confirm their account
- 🔑 **Password Recovery** — Request password reset via email with a time-limited token
- 📇 **Contacts Management** — Create, read, update, and delete personal contacts
- 📄 **API Documentation** — Integrated Swagger UI for exploring and testing endpoints
- ⚙️ **Error Handling & Validation** — Centralized error middleware and input validation
- 🧩 **Modular MVC structure** — Clean and maintainable project architecture

---

## 🛠️ Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB + Mongoose**
- **JWT** for authentication
- **Nodemailer** for email services
- **Swagger** for documentation
- **dotenv**, **bcrypt**, **Joi**, and other utilities
